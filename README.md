# Minimalist Notepad

A clean, simple notepad app with real-time character and word counters.

## Features

- 🔤 **Character Counter** - Real-time character count display
- 📝 **Word Counter** - Real-time word count display
- 💾 **Auto-Save** - Content automatically saved to browser's local storage
- 🎨 **Minimalist Design** - Clean, distraction-free interface
- 📱 **Responsive** - Works on desktop and mobile devices

## Usage

Simply open `index.html` in any modern web browser. Your notes will be automatically saved and restored when you return.

## Technologies

- Pure HTML5
- CSS3
- Vanilla JavaScript
- No external dependencies

## How It Works

The app uses:
- `localStorage` to persist your notes between sessions
- Real-time JavaScript event listeners to update counters as you type
- Clean, modern CSS with flexbox for layout
