# Minimalist Notepad

A sleek, dark-themed notepad app with real-time character and word counters built with Tailwind CSS.

## Features

- 🔤 **Character Counter** - Real-time character count with icons
- 📝 **Word Counter** - Real-time word count with icons
- 💾 **Auto-Save** - Content automatically saved to browser's local storage
- 🎨 **Dark Theme** - Beautiful dark minimalist design
- 📱 **Responsive** - Works seamlessly on desktop and mobile devices
- ✨ **Custom Scrollbar** - Styled scrollbar matching the dark theme
- 🎯 **Focus Indicator** - Subtle ring effect on focus

## Usage

Simply open `index.html` in any modern web browser. Your notes will be automatically saved and restored when you return.

## Technologies

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- No build process required

## Design Highlights

- **Dark Color Scheme** - Easy on the eyes with gray-900/950 palette
- **Minimal UI** - Clean counter bar with icons and auto-save indicator
- **Smooth Interactions** - Subtle animations and transitions
- **Typography** - Optimized for readability with relaxed line height

## How It Works

The app uses:
- `localStorage` to persist your notes between sessions
- Real-time JavaScript event listeners to update counters as you type
- Tailwind CSS utility classes for rapid, responsive styling
- Custom scrollbar styling for a cohesive dark theme experience
